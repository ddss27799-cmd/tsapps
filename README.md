# tsapps — smallprivatemassendger

Репозиторий для приложения мессенджера под мобильные устройства и ПК и вспомогательного сайта для скачивания.

Описание: `smallprivatemassendger` (опечатка сохранена из описания репозитория).

Структура, которую я добавил как старт:
- /website — простой HTML сайт с ссылками для скачивания APK/IPA/PKG/EXE
- /apps/mobile — место для кода мобильного приложения (предлагаю React Native / Expo)
- /apps/desktop — место для кода десктопного приложения (предлагаю Electron или Tauri + React)
