# Contributing to TSApp

Спасибо, что хотите внести вклад в TSApp! Это руководство поможет вам начать.

## Как внести вклад

### Сообщение об ошибках

Если вы нашли ошибку, пожалуйста:

1. **Проверьте**, не была ли эта ошибка уже зарегистрирована
2. **Откройте Issue** с детал��ным описанием
3. **Включите** информацию о версии, ОС и шагах для воспроизведения

### Запросы функций

1. **Откройте Issue** с предложением
2. **Опишите** предполагаемое поведение
3. **Объясните**, почему это полезно

### Pull Requests

1. **Форкните репозиторий**
2. **Создайте ветку** (`git checkout -b feature/AmazingFeature`)
3. **Коммитьте изменения** (`git commit -m 'Add AmazingFeature'`)
4. **Отправьте ветку** (`git push origin feature/AmazingFeature`)
5. **Откройте Pull Request**

## Стиль кода

- Используйте TypeScript
- Следуйте eslint конфигурации
- Используйте prettier для форматирования
- Пишите понятные коммит-сообщения

## Тестирование

- Убедитесь, что все тесты проходят
- Добавьте тесты для новых функций
- Поддерживайте 80%+ покрытие

## Коммуникация

- Будьте вежливы и уважительны
- Помогайте другим разработчикам
- Делитесь идеями в Discussions

## Лицензия

Любой вклад, который вы внесёте, будет распространяться под лицензией MIT.
